## 과제 셀프회고

학생 신분으로 참여하여 처음 테스트를 진행하는 단계부터, 이벤트 위임의 동작, SPA에서의 라우트 원리까지 각 과정이 쉬운길은 아니었지만 직접 SPA를 개발하며, 기존에 사용하던 라이브러리, 프레임워크에서 어떤 동작을 해주고 있었는지 배울 수 있었습니다.
아직 좋은 코드가 무엇인지 어떻게 작성해야하는지에 대한 기준과 지식이 쌓이지 않아, 다른 분들으 코드를 보며 배우고 익히는 과정을 앞으로 해야하지 않을까 싶습니다.
1주차 과제를 진행하며, 무엇을 알고있는지, 모르는것이 무엇이었는지, 앞으로 어떤 공부를 해야하는지가 조금 명확해졌습니다.

### 기술적 성장

- SPA의 기본 동작을 학습하였습니다.
- 최적의 Router 구성하기 위해 여러 디자인패턴을 적용할 수 있음을 배웠습니다.
- 이벤트 위임방식을 통해 이벤트를 동적으로 관리할 수 있음을 배웠습니다.
- 사용자의 상태 관리를 객체로 관리하여, 객체 생성 패턴을 익혔습니다.
- 기본적인 테스트 코드를 학습할 수 있었습니다.

### 코드 품질

- 라우트를 하는 로직에서 라우트 모드, 로그인 상태에 따른 하나의 인터페이스를 설계하여 각 라우트 모드별로 다른 라우터를 구성하지 않아도 동작할 수 있도록 만들었습니다.
- 각 페이지마다 작성하던 이벤트 처리를 하며 중복된 코드를 줄이고자 이벤트 위임 방식을 적용해 이벤트를 관찰하고 관리하도록 구현하였습니다. - 다만 관리해야하는 이벤트가 많아지면 이벤트 처리 로직을 각 컴포넌트로 분리해야함을 인지하였습니다. 이에 대한 해결 방법을 멘토링 시간에 알게되었습니다(밑의 코드입니다.). 배운점을 적용시키기 위해서 많은 코드들의 수정이 필요해 적용시키지 못하였지만, 해당 방식을 별도로 학습하고자 합니다.

### 학습 효과 분석

- 라우트를 설계할 수 있는 다양한 방법들을 학습자료를 통해 배울 수 있었고, 기존에 늘 하던 방식에서 다양하게 코드를 짤 수 있는 역량을 키우기 위해 노력해야함을 깨닫게 되었습니다.

### 과제 피드백

- 학습 자료에 있는 여러 방법들에 대해 처음 과제를 진행하는 시점에 온전히 이해하지 못하였으며, 해당 과제를 수행하는데 어느 시간이 소요될지 파악이 되지않아 과제를 빠르게 진행하였습니다. 따라서 학습자료에서 제시하는 여러 방법을 적용하지 못한 아쉬움이 큽니다.
- 디자인 패턴을 통해 라우터를 구성하지는 못해, 꼭 라우터에 여러 디자인 패턴을 적용시키고 싶습니다.
- js의 기본 문법에 있어서 "다양한 함수를 적절히 사용했나"에 대한 의문이 있습니다.
- 아직 현업을 경험해보지 못하였고, 코드 리뷰를 해본 경험이 없어, 작성한 코드가 괜찮은 코드인지, 또는 많이 수정을 해야하는지에 대한 기준이 아직 미미합니다. 앞으로의 과제를 진행하며 받을 여러 피드백을 바탕으로 꾸준히 발전해야겠다는 생각을 했습니다.
